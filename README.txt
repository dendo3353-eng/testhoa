# Khu vườn hoa — bản GitHub Pages

## Cách đưa lên GitHub
1. Giải nén ZIP này.
2. Mở repository `testhoa` trên GitHub.
3. Tải **toàn bộ nội dung bên trong thư mục** lên thư mục gốc của repository (không tải nguyên thư mục lồng bên ngoài).
4. Nếu GitHub hỏi ghi đè `index.html` hoặc `garden_data.json`, chọn ghi đè.
5. Vào Settings → Pages và chọn Deploy from a branch → `main` → `/ (root)` → Save.
6. Chờ GitHub Pages triển khai rồi mở `https://dendo3353-eng.github.io/testhoa/`.

## Các file cần có
- `index.html`
- `garden_data.json`
- `anh1.jpg` đến `anh10.jpg`
- `music.mp3`

Ảnh và nhạc được tham chiếu bằng đường dẫn tương đối nên hoạt động trong repository Pages `/testhoa/`.
Nhạc chỉ bắt đầu sau khi khách truy cập nhấn nút “Bật nhạc” do quy định tự phát của trình duyệt.

## Lưu ý
Đây là bản dựng lại gọn, tự chứa dựa trên ảnh, lời chúc và nhạc có trong ZIP bạn gửi. Nó có trang chào, bộ sưu tập ảnh, xem ảnh lớn, lời chúc và nhạc nền. Vì ZIP ban đầu không có mã JavaScript/CSS và thư mục tài nguyên 3D gốc, bản này **không thể khôi phục chính xác hiệu ứng vườn 3D của website gốc**.
